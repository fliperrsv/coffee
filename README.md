# ☕ Кофейня «Берёза»

Одностраничный сайт кофейни в Рузах. Учебный проект для портфолио.

## О проекте

Промо-сайт кофейни: герой-блок, меню с ценами, галерея зала,
анимированные цифры, слайдер отзывов и форма бронирования столика.

## Технологии

- HTML5 — семантическая вёрстка
- CSS3 — адаптивная сетка, переменные, анимации (Ken Burns, reveal-эффекты)
- JavaScript (чистый, без библиотек) — бургер-меню, маска телефона,
  валидация формы, слайдер, счётчики, прелоадер
- Изображения сгенерированы в «Шедевруме»

## Возможности

- Полностью адаптивная вёрстка (мобильные, планшеты, десктоп)
- Плавное появление блоков при прокрутке
- Слайдер отзывов с автопрокруткой
- Форма бронирования с валидацией и маской телефона
- Автономная работа: все изображения хранятся локально

## Запуск

Откройте index.html в браузере — сборка и зависимости не нужны.
